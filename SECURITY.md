# Security

Please report security problems in the SigPen MCP server or the SigPen app to [support@sigpen.com](mailto:support@sigpen.com) with "Security" in the subject. Don't open a public issue for them.

Tell us what you found, how to reproduce it, and what an attacker could do with it. We'll confirm we got your report within two business days.

The server is hosted at `https://www.sigpen.com/api/mcp`. This repository only holds setup instructions and client plugins, so most reports belong to the hosted service.
